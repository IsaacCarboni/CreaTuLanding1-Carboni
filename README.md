# Bodega de Isa 🍷

¡Bienvenido a la **Bodega de Isa**! Este es mi proyecto final para el curso de **React JS** en Coderhouse. Es un e-commerce enfocado en la venta de vinos de alta gama.

## 🚀 Demo
Podés ver la aplicación funcionando aquí: [bodega-isa-react.vercel.app](https://bodega-isa-react.vercel.app)

## 🛠️ Tecnologías utilizadas
* **React JS** (Vite)
* **Firebase** (Firestore para la base de datos)
* **Vercel** (Para el despliegue/hosting)
* **React Router Dom** (Para la navegación)

## 📦 Funcionalidades
* Catálogo de productos dinámico desde Firebase.
* Filtrado por categorías (Tintos, Blancos, Espumantes).
* Detalle de producto individual.
* Carrito de compras funcional con contador.
* Formulario de Checkout que genera una orden de compra en la base de datos.
